# WukongBenchAuto

Сама прогоняет Black Myth: Wukong Benchmark Tool два раза (CPU-тест и GPU-тест) и сохраняет отчёт: железо, результаты, настройки.

## Нужно
- Windows 10/11
- Steam с установленным [бенчмарком](https://store.steampowered.com/app/3132990/)
- .NET SDK 7+

## Запуск
`запуск.cmd` или:

```bash
dotnet run -c Release --project Исходники/WukongBenchAuto
```

Занимает 8-15 минут. Мышь и клавиатуру в это время не трогать: программа сама жмёт кнопки в меню бенча.

Отчёт: `results/<дата_время>/report.md` в папке проекта (как ни запускай: из Visual Studio или через `запуск.cmd`).

## Настройки тестов
| | CPU-тест | GPU-тест |
|---|---|---|
| Разрешение | 1280x720, масштаб 33% | родное, 100% |
| Качество | Низкое | Реалистичное |
| Трассировка лучей | выкл | Ультра (если не хватит видеопамяти, повтор без неё) |
| Генерация кадров, VSync | выкл | выкл |

Ваши настройки игры сохраняются перед тестом и возвращаются после.

## Параметры
```
--only cpu|gpu   только один тест
--no-rt          без трассировки лучей
--out <папка>    куда сохранять отчёт
--help           все параметры
```
